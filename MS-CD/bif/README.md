# BIF data directory

Place the following files in this directory before running the benchmark:

- `alarm.bif`
- `alarm3.bif`
- `alarm10.bif`
- `child3.bif`
- `child5.bif`
- `child10.bif`
- `andes.bif`
- `pigs.bif`

The BIF files are intentionally not included. Confirm their original licenses and document how the derived `*3`, `*5`, and `*10` networks were generated before publishing the benchmark.
